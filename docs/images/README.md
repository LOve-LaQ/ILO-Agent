## 拍摄建议

- 统一分辨率（建议 1440 宽）与浏览器缩放，避免各图参差不齐
- 终端截图建议浅色主题、放大字号，确保关键字段（`score` / `rating` / `new_interval`）清晰可读
- 隐藏书签栏与个人信息，避免暴露本地隐私
